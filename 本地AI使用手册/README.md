# AI 使用手册

这是一个可直接用 Obsidian 打开的 AI 工程知识库，用来持续记录：

- AI 在前端、后端以及跨领域工程任务中遇到的真实问题；
- 已验证的修复方式、检查动作和可复用经验；
- 尚未验证、需要后续整理的线索。

从 Obsidian 打开本目录后，先进入 [[首页]]。工作区级默认规则位于 [[AGENTS]]，完整流程见 [[使用与维护说明]]，AI 接入细则见 [[AI接入规则]]。新问题先放入 [[99-收件箱/收件箱]]，验证完成后再移动到对应的前端、后端或通用分类。

**位置与任务区联动**：本库位于 `G:\AIrenwu\本地AI使用手册`，是 [G:\AIrenwu 任务区](../README.md) 的第 7 类文件夹（2026-11-16 由 `E:\本地AI使用手册` 迁入，E 盘已不存在；旧文档里的 E 盘路径按此理解）。任务区的可复用脚本在 [脚本库](../脚本库/)，任务证据在 [01_任务归档](../01_任务归档/)；联动规则见 [[03-通用/04-工程规范与安全/规则-任务区与手册一体化联动]]。

## 顶层结构

| 目录 | 用途 |
| --- | --- |
| `01-前端` | 页面、浏览器、组件、状态、接口联调、构建和前端质量问题 |
| `02-后端` | 服务、API、业务、数据库、安全、并发、部署和后端质量问题 |
| `03-通用` | 同时影响前后端，或与 AI 工程协作、验证流程相关的问题 |
| `90-模板` | 新建记录时复制的模板和命名规范 |
| `99-收件箱` | 尚未完成复现、定位或验证的材料 |

## 最短使用流程

1. 按 [[90-模板/记录命名规范]] 命名，复制 [[90-模板/问题记录模板]]，或先在 [[99-收件箱/收件箱]] 记录线索。
2. 按主要影响面将记录放到 `01-前端`、`02-后端` 或 `03-通用` 下的细分类目。
3. 只有完成复现、根因定位、修复和验证后，才把状态改为 `verified`。
4. 在对应的 `索引.md` 中补充记录链接，方便 AI 按关键词检索。

## 记录边界

- 记录事实、证据和验证结果，不把猜测写成规则。
- 不保存密码、Token、API Key、私钥、Cookie、个人隐私或生产敏感数据。
- 保留“适用条件”和“不适用范围”，避免把单次经验误用到所有项目。
- 历史记录不静默改写；规则变化时新增记录，并标记旧规则为 `deprecated`。
