# 问题：深色仪表盘的"次级文字"在深底上发糊

## 一句话结论

从参考截图里"取占比最高的颜色"来定灰阶，会把**抗锯齿混色后的偏暗值**当成设计色，
结果最暗两档的对比度只有 **3.27:1 / 2.25:1**，双双低于 WCAG AA 的 **4.5:1**；
而这些"最安静的"颜色往往承载着**真实数据**（表格数值、坐标刻度、图例），不是装饰。

## 触发条件与影响

- 项目或功能：深色自绘仪表盘（本例：卡片底 `#10131d` 的悬浮面板）
- 环境与版本：与框架无关；只要背景是深色、字号偏小就会踩
- 触发条件：灰阶靠"看"或"从截图取色"决定，而不是按对比度公式算
- 影响范围：全部卡片标签、表格列头与次要数值、图表坐标刻度、图例文字

## 复现步骤

1. 前置条件：卡片底 `#10131d`，次级文字用 `#5c6878` / `#454f63`
2. 操作：按 WCAG 2.1 公式算对比度
3. 预期结果：≥ 4.5:1（AA 正文阈值）
4. 实际结果：3.27:1 / 2.25:1 —— 明显不达标

## 证据

改动前四档灰（底色 = 卡片 `#10131d`，相对亮度 L=0.00627）：

| 档位 | 色值 | 对比度 | 判定 |
|---|---|---|---|
| FG 正文 | `#e8edf5` | 15.77:1 | 达标 |
| DIM 次级 | `#8a97a8` | 6.24:1 | 达标 |
| **FAINT 标签** | `#5c6878` | **3.27:1** | **不达标** |
| **MUTED 图例** | `#454f63` | **2.25:1** | **不达标** |

关键判断：`MUTED` 在代码里画的是**真实数据**——表格里的命中率/TOKEN 数值、趋势图左右轴刻度、
四色图例文字、24 小时时刻刻度。2.25:1 叠在 8.5pt 小号字上，就是"发糊"。

修复后（四档全部 ≥4.5:1，色相族与层次不变）：

| 档位 | 旧 | 新 | 旧对比度 | 新对比度 |
|---|---|---|---|---|
| FAINT | `#5c6878` | `#7f8b9e` | 3.27:1 | **5.37:1** |
| MUTED | `#454f63` | `#757f93` | 2.25:1 | **4.60:1** |

实拍复核：改后截图里旧两色像素数 = **0**，新两色 = 4030 / 1025 像素（改色确实落到画面上了）。

## 根因分析

- 已确认的根因：
  1. 配色是"从用户参考图实测占比最高色"得来的 —— 截图里文字是抗锯齿渲染的，
     占比最高的往往是**文字与背景的混色**，比设计值更暗；
  2. 四级灰阶没有做过对比度校验，最暗两档直接落到 AA 线以下；
  3. 更关键的是**误判了语义**：以为最暗那档是"装饰性提示"，
     实际上它承担了数据可读性。
- 排除过的假设：以为是显示器/亮度问题（同一张图在别处也糊），以为是字号太小（放大后仍偏暗）。
- 问题归属：修改前已有（设计令牌来源不可靠）

## 最小修复

按 WCAG 2.1 算一遍，把整个次级色阶**上移一档**（不是只改最暗那一档）：

```python
def _lin(c):
    c /= 255.0
    return c/12.92 if c <= 0.04045 else ((c+0.055)/1.055) ** 2.4

def lum(hx):
    r, g, b = (int(hx[i:i+2], 16) for i in (1, 3, 5))
    return 0.2126*_lin(r) + 0.7152*_lin(g) + 0.0722*_lin(b)

def contrast(fg, bg):
    a, b = sorted((lum(fg), lum(bg)), reverse=True)
    return (a + 0.05) / (b + 0.05)
```

选色目标：`L_text >= 4.5 * (L_bg + 0.05) - 0.05`。

## 可复用规则

- **深色主题的灰阶一定要算，不要看**。目标：正文 ≥4.5:1；承载数据的最小号字同样按 4.5:1；
  纯装饰线条才允许 3:1。
- **不要从截图的"占比最高色"推导设计令牌** —— 抗锯齿会把颜色往背景方向拉。
  要取色就从**纯色块内部**取（避开边缘 2px）。
- 改灰阶时**整档上移**而不是只补最暗一档，否则层次会被压平、最高档会顶到正文色。
- 验收要用像素复核：改色后统计实拍图里旧色像素数，应为 0。

## 适用范围与不适用范围

- 适用：深色仪表盘、代码编辑器主题、任何小字号 + 深底的界面
- 不适用：纯装饰性水印/分割线（可低于 4.5:1）；大面积色块（按非文本对比度 3:1 判定）

## 剩余风险

- 四档灰在深底上全部达标后，相邻两档的视觉差异会变小（本例 5.37 vs 4.60），
  层次感弱于"不达标但对比强"的旧方案 —— 这是可读性与层次感的取舍，需要产品确认。
- 用户自定义主题/透明度（本例面板支持 `alpha` 0.78~1.0）会改变实际对比度，
  低透明度下需重新评估。
