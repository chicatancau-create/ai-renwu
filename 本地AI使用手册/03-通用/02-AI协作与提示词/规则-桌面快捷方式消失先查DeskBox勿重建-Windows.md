# 规则：桌面快捷方式不见了 ≠ 被删了，先扫 `E:\DeskBox` 再决定

> 本条是**行为规则**，不是代码缺陷。触发场景：AI 按「交付必带桌面快捷方式」建好 `.lnk`，隔一段时间复查发现桌面没有这个 `.lnk`。

## 一句话结论

用户会主动把桌面上的快捷方式移进 `E:\DeskBox\<分类>\`，所以**复查发现桌面快捷方式"消失"时，第一动作是去 DeskBox 全文扫一遍确认是否被移动；确认没有才谈重建**。直接重建会在桌面留下重复品，且违背用户"桌面清空"的意图。

## 触发条件与影响

- 项目或功能：任何给 Windows 桌面建 `.lnk` 的交付（软件部署、工具链准备）
- 环境与版本：Windows 11（28000）· `E:\DeskBox` 作为用户的快捷方式收纳库
- 触发条件：AI 事后复查桌面，`glob('C:\Users\Admin\Desktop\*.lnk')` 里找不到自己建的那个
- 影响范围：交付物状态判断错误 → 多余写入 → 用户桌面被再次弄乱

## 复现步骤

1. 前置条件：AI 在桌面建过 `.lnk` 并当场核验通过（读回 `TargetPath`、确认目标存在）
2. 操作：过一段时间（本例约 20 小时）复查桌面
3. 预期结果：快捷方式仍在桌面，或明确知道被移到哪里
4. 实际结果：桌面 `.lnk` 计数为 0；AI 未先查 DeskBox 就重建，把用户已经归位的东西又变回桌面重复品

## 证据

2026-10-31 实测，两条快捷方式都被用户移进了同一个分类目录：

```
E:\DeskBox\实用小工具\K30Ultra-Root 工具箱.lnk   673 B   改 2026-10-31 11:27   内含 D:\K30Ultra-Root
E:\DeskBox\实用小工具\安卓去广告.lnk           1018 B   改 2026-10-31 18:21   内含 D:\AndroidAdCleaner\...\AndroidAdCleaner.exe
C:\Users\Admin\Desktop\*.lnk                    数量 0
```

DeskBox 是**带分类的收纳库**，不是回收站，顶层实测有：`VPN`、`刷课软件`、`剪辑工具`、`学习软件`、`实用小工具`、`广告屏蔽`、`性能监控与优化`、`我的桌面`、`文件及文档`、`新增-AI与开发工具`、`新增-其他工具`、`新增-影音与创作`、`新增-游戏与修改`，且每个分类旁边配一个同名 `.lnk`（说明用户是从桌面进分类、再从分类进程序）。

## 根因分析

- 已确认的根因：用户维护"桌面零快捷方式"的习惯，交付物建完后由他本人归档到 DeskBox；AI 把"桌面没有"当成"被删除"是**状态误读**。
- 排除过的假设：不是清理工具删的（文件在 DeskBox 里完好、目标有效）；不是建失败（当场核验过 `TargetPath` 与目标存在）。
- 问题归属：**本次 AI 判断引入**（该查没查，直接重建）。

## 最小修复

复查交付物是否还在时，把"桌面存在性"换成"全盘存在性"：

```bash
# 第一步永远是这个，而不是 CreateShortcut
python -X utf8 -c "import glob; [print(p) for p in glob.glob(r'E:\DeskBox\**\*.lnk', recursive=True) if '关键词' in p]"
```

扫到 → 什么都不做，只在汇报里写明"已被移到 `E:\DeskBox\<分类>\`"。
扫不到 → 再查桌面与回收站，确认确实丢失才重建，并告知用户重建位置。

## 可复用规则

1. **交付时**：桌面建 `.lnk` 后当场核验（读回 `TargetPath` + 确认目标文件存在），并在汇报里同时给出**程序本体的绝对路径**——因为用户会把快捷方式移走，只报"桌面上有图标"会失效。
2. **复查时**：桌面找不到 → 先 `glob(r'E:\DeskBox\**\*.lnk', recursive=True)` 按名字匹配；命中即视为"仍在交付状态"，**不重建**。
3. **归类建议**：可以指出"某分类目录似乎更贴切"（如 `广告屏蔽\` vs `实用小工具\`），但**不擅自移动用户整理好的文件**。
4. 例外：如果用户明确说过"这次别动/就放桌面"，按当次指令优先。

## 适用范围与不适用范围

- 适用：本机上任何由 AI 创建、期望用户双击打开的桌面入口（`.lnk`、`.url`、脚本快捷方式）
- 不适用：用户要求放在固定路径的产物（工作区文件、D 盘工具链本体）——那些不以桌面为入口；也不适用于用户明确禁止移动的场景

## 剩余风险

- DeskBox 的分类目录会增长，只扫一层会漏 → 必须用 `recursive=True`。
- 用户也可能**真的删掉**某个快捷方式（不满意该交付）。扫不到时不要假定是"被移走"，要回落到"确认丢失"分支并询问。
- 本规则只描述用户到 2026-10-31 为止的习惯，属可观察行为而非其明示的永久承诺；与用户当次指令冲突时以当次指令为准。
