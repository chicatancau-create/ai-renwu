# 问题：按别人的模板填表，数据全对但版面不能交付

## 一句话结论

模板里的列宽常常是**按示例行的占位内容（`xxx`、`xx年xx月xx日`、一段长说明）自动撑出来的**，不是设计值。
原样沿用会同时出现两种坏法：**窄列的 11 位号码被截成看得见的半截**、**超宽列把右侧列推到页尾**。
套模板时必须按「本轮最长真实内容」重量列宽，并且**必须导 PDF 逐页目视**才算签收。

## 触发条件与影响

- 项目或功能：2026-2027 大二学年违纪情况表（`G:\AIrenwu\01_任务归档\2026-11-15_大二学年违纪表填报`），模板来自 2026-10-09 那版。
- 环境与版本：本机 Python 3.1x + openpyxl 3.1.5 + 桌面版 Excel（COM 自动化）。
- 触发条件：`openpyxl.load_workbook(模板)` 后只改值不改 `column_dimensions`，直接另存交付。
- 影响范围：数据核对全绿也会被判「没填好」；号码不可读比缺数据更难解释。

## 复现步骤

1. 前置条件：模板 A=23.66 / B=32.78 / C=5.89 / D=26.55 / E=156.66 / F=10.11 / G=15.11（单位：字符宽）。
2. 操作：按模板写 24 行数据（C 列 11 位手机号，E 列 5–18 字说明），保存。
3. 预期结果：六列一屏内排开，号码完整。
4. 实际结果：C 列只露出不到一半号码；E 列 156 宽让 `处理结果`/`备注` 飘到页面最右，中间空一大片；
   班级名在 A 列临界截断。

## 证据

- 第一版导出的 PDF：`处理结果` 与 `备注` 被挤到页尾远端，`情况说明` 表头居中在 156 宽的列里，形成整列空白。
- 第二版（重设列宽 A25 / B11 / C14.5 / D21 / E60+wrap / F10.5 / G9.5）同一份数据导 PDF：
  班级全称、11 位号码、说明文字完整，`备注` 红字「校规」在页内连续可见。

## 根因分析

- 已确认的根因：模板的 `column_dimensions` 是制作者当时示例内容的副产物——E 列 156 因为示例行里那句
  「（迟到/踩点、早退、晚归/旷课…）注意：旷课按课时算…」很长，C 列 5.89 因为示例只写了 `xxx`。
- 排除过的假设：不是字体/行高问题（同批 `踩坑-openpyxl写的xlsx在Excel里行高被裁字` 管的是纵向裁字，本例是横向）；
  不是打印缩放（`FitToPagesWide` 开关不影响列内截断）。
- 问题归属：模板继承（既有模板自带），不是本轮改动引入。

## 最小修复

```python
anchors = 22  # 11 位号码 + 边距的经验下限：width >= 13.5
for col, width in {"A": 25, "B": 11, "C": 14.5, "D": 21, "E": 60, "F": 10.5, "G": 9.5}.items():
    ws.column_dimensions[col].width = width
# 长文本列开自动换行，纵向靠行高兜底（行高规则见「行高被裁字」那条）
ws.cell(row=r, column=5).alignment = Alignment(horizontal="center", vertical="center", wrap_text=True)
```

不改表头、字体、字号、合并与居中——**格式要求=结构+表头+颜色，列宽属于可调的版面参数**。

## 可复用规则

1. **接到别人模板先量宽**：逐列取「本轮最长真实值」估宽（CJK 按 2 个单位），与模板值比对，差太多就改；
   11 位手机号 ≥ 13.5，中文班级全称按 `len*2` 再留 2。
2. **超宽列是坑不是好意**：单列 > 90 基本可判是示例长文本撑出来的，收窄并开 `wrap_text`。
3. **交付前一定导 PDF 目视**：数据核对通过不等于版面通过；导出后用 Read 直接看 PDF 页图最快。
4. 模板里的**示例说明行**（如「（班规/校规）」提示行）在正式表里要删掉，否则会被当成一条数据。

## 适用范围与不适用范围

- 适用：openpyxl / xlsxwriter 往既有模板里填数据；列里存在定长编码（电话、身份证、单号）或超长中文说明的报表。
- 不适用：用户明确要求「一个像素都不许动模板」的场景（此时改为交双份：原格式版 + 可读版）；
  纯数值窄表；在 Excel 里手工编辑的场合（Excel 会自己撑列）。

## 剩余风险

- 列宽按字符宽估算，换字体（非等线/宋体）或 WPS 打开可能有 1–2 字误差；WPS 分页未实测。
- 手机号来自 QQ 群昵称，若同学改昵称会过期，正式上报前建议对一遍通讯录。
