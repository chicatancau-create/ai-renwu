# 任务开始检查清单

## 范围与上下文

- [ ] 读取任务要求、相关 README、`AGENTS.md` 和贡献指南。
- [ ] 检查工作区状态，确认用户已有修改不会被覆盖。
- [ ] 找到相关入口、调用链、数据流、配置、迁移和外部服务。
- [ ] 记录项目名、仓库路径、语言、框架、包管理器和锁文件。

## 规范与历史

- [ ] 阅读相邻 2～3 个同类文件，确认格式和架构约定。
- [ ] 用项目名、技术栈、命令和错误关键词检索项目索引、模式和复盘。
- [ ] 判断命中经验的适用条件、例外和验证证据。

## 风险与计划

- [ ] 明确正常、失败、空值、权限、并发和兼容性边界。
- [ ] 区分修改前问题、本次可能引入的问题和环境/外部服务问题。
- [ ] 仅计划完成当前需求所需的最小合理改动。
