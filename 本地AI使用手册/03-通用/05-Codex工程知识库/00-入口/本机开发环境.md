## 未安装或未发现

pnpm、Yarn、Bun、uv、Go、Rust/Cargo、Docker、VS Code CLI。它们不是所有项目的通用前置条件；只有项目文档、锁文件或任务明确需要时再安装，并优先遵循项目指定版本。

## 使用边界

- 工具存在不代表适合当前项目；必须先读取项目索引、版本文件和锁文件。
- 不全局安装项目依赖，不混用包管理器，不擅自升级 SDK。
- Git 全局用户名、邮箱、签名和远程凭据尚未配置；应由用户或具体项目要求决定。
- 本知识库当前不是 Git 仓库，因此不能对它运行 `git diff`；审查修改时使用文件清单、内容重读和等效差异记录。
