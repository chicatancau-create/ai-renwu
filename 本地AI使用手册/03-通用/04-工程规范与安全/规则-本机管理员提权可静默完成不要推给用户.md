# 问题：需要管理员的活被我写成了"请你双击这个脚本"

## 一句话结论

本机 `ZHOUMO\Admin` 在 `Administrators` 组内、且 UAC 的 `ConsentPromptBehaviorAdmin=0`，
所以**从非提权的 DSH 会话里用 `Start-Process ... -Verb RunAs` 可以直接静默提权**（子进程 `admin=True`，无 UAC 弹窗）。
因此"需要管理员"不是把活推回给用户的理由：**能自己提权跑完的，就自己跑完再报告结果**，
不要把"文件在哪、请你双击、请点 UAC 的是"这类话写进交付物。

## 触发条件与影响

- 项目或功能：任何需要管理员权限的清理/注册表/服务/计划任务操作（本次是 `C:\Windows\Logs` 等系统目录清理）
- 环境与版本：本机 `pwsh` 实为 **Windows PowerShell 5.1.28000.3086（Desktop）**；DSH 会话以 `ZHOUMO\Admin` 身份运行但**非提权令牌**
- 影响：上一版交付把"双击 `run-system-cleanup.cmd` 并点 UAC"列为"只剩两件需要你动手"之一，
  用户回（m01436）：**「最后一件事你自己做！他喵的，你给我的这个脚本，我连位置都不知道，你让我怎么搞」**
  —— 交付物看起来是"我该做的做完了"，实际把最容易失败的一步（找文件、看菜单、点弹窗）留给了用户

## 怎么判断本机能不能静默提权（三步，只读，先查再决定）

```powershell
# ① 当前进程是否已提权，以及是谁在跑
$id = [Security.Principal.WindowsIdentity]::GetCurrent()
$id.Name
([Security.Principal.WindowsPrincipal]$id).IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)

# ② 我这个账户到底在不在管理员组（IsInRole=False 不代表不在组里，只代表令牌没提权）
net localgroup Administrators

# ③ UAC 提权策略：ConsentPromptBehaviorAdmin=0 才是"管理员提权不提示"
Get-ItemProperty 'HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System' |
  Select-Object EnableLUA, ConsentPromptBehaviorAdmin, PromptOnSecureDesktop
```

本机实测值（2026-11-16）：`EnableLUA=1`、**`ConsentPromptBehaviorAdmin=0`**、`PromptOnSecureDesktop=0`，
`net localgroup Administrators` 成员含 `ZHOUMO\Admin` 与 `Administrator`。

判据：

| `ConsentPromptBehaviorAdmin` | 管理员账户提权时的行为 |
|---|---|
| `0` | **不提示，直接提权**（本机） |
| `1` | 提示，需要凭据输入 |
| `2` | 在安全桌面提示"是/否" |
| `5`（默认） | 在安全桌面提示"是/否"（非 Windows 二进制才提示） |

另：`EnableLUA=0` 时根本不走 UAC，`-Verb RunAs` 会直接以当前令牌启动（等于没提权）；这种机器要另想办法。

## 正确的提权跑法（含一个必须知道的限制）

```powershell
$p = Start-Process -FilePath 'powershell.exe' `
      -ArgumentList '-NoProfile','-ExecutionPolicy','Bypass','-File',"`"$workerPs1`"" `
      -Verb RunAs -PassThru -WindowStyle Hidden
$p | Wait-Process -Timeout 900 -ErrorAction SilentlyContinue
# 子进程结果读它自己写的日志文件
```

- **`Start-Process -Verb RunAs` 不支持重定向 stdout/stderr**：`-RedirectStandardOutput` 会报参数冲突。
  要拿结果就让子进程自己写文件（本次写在 `02_证据日志\system_cleanup_APPLY_<时间戳>.log`），父进程 `Wait-Process` 后读该文件。
- 必须 `-PassThru` 才有 `$p` 可等；`Wait-Process -Timeout` 超时要自己判，别无限等。
- 仍要保留"自我提权护栏"环境变量（`_SYS_CLEANUP_ELEVATED`）的 `.cmd` 入口，供人工双击时复用；
  但**不要把它当成"交付给用户的那一步"**。

## 可复用规则

1. 遇到"需要管理员"的活，**先跑上面三步判据**，能静默提权就直接做，做完把日志路径和数字报给用户。
2. 只在"确实需要用户在场"的情况才回推：要输密码（`ConsentPromptBehaviorAdmin` 为 1）、要改 BIOS/固件、
   要关机重启、或涉及不可逆且需要用户决策的操作（如关休眠省 12 GB）。
3. 交付物里**不要出现"请你双击/请你找这个文件"**；如果非要保留一个手工入口，也必须同时说明"我已经用管理员跑过了，这只是留给你以后用"。
4. 判据优先于印象：`IsInRole(Administrator)=False` 只说明**当前令牌**没提权，不能推出"这台机器提不了权"——
   我上一版报告就是这么把结论写错的。

## 适用范围

本机（`ZHOUMO\Admin` 账户 + 当前 UAC 策略）。换机器、换账户、或组策略改过 `ConsentPromptBehaviorAdmin` 后要重新跑三步判据。

## 剩余风险

- [ ] 未在"`ConsentPromptBehaviorAdmin=1`（要求输入凭据）"的机器上验证——那种情况静默提权会失败或挂起，需人工
- [ ] 未验证杀软/EDR 拦截 `-Verb RunAs` 隐藏窗口启动的情况
- [ ] `EnableLUA=0` 的机器上该方法不成立（会以当前令牌启动，看似成功实则没权限）
